# 会议纪要汇总

第一次会议

时间 2025.9.22 地点 图书馆研讨间

主题：初步商讨项目可选方案

初步制定项目可选方案有三个：

首先是做一个校园菜品点评小程序；其次是做一个文献便捷管理工具；再其次是执行可选命题的无人机平台

对校园菜品点评小程序进行了具体的原型概念设计，决定参考大众点评、虎扑、完美世界平台等手机APP，进行了小程序大致的菜品信息展示页面和菜品评论相关页面的概念设计。



第二次会议

时间 2025.9.28 地点 图书馆研讨间

主题：确定项目主题和讨论项目具体可行性

主要内容：

在9.26就数据获取问题咨询指导教师的帮助，但在与食堂方面沟通之后，食堂并不提供菜品的任何数据

讨论决定在十一期间手动录入获取数据，通过视频和拍照直接记录数据，然后导入 excel 表格；并且给每个成员分配了具体的要去哪些食堂获取和整理数据

同时商讨了具体的项目前后端的规划，决定制作两个前端，分别是小程序端作为客户端，和网页的管理端作为食堂管理，并且要在食堂管理端添加菜品批量上传的功能；

之后对项目进行了可行性和工作量的评估，决定确认选题为制作校园餐品点评平台，项目名称命名为**食鉴-TasteInsight**



第三次会议

时间 2025.10.15 地点 图书馆研讨间

主题：项目初步原型设计、技术方案制定和初步分工

使用墨刀创建了网页端的原型设计，设计了网页端的主要样式和色调，并且对网页端主要功能进行原型设计，包括菜品添加、修改、审核，菜品批量上传，人员权限管理

讨论了前后端的技术方案，初步制定前端技术方案，使用vue3框架写网页端，使用基于 Vue3 语法的 Uniapp 框架，前后端均使用 TypeScript 语言，后端用 Prisma 作为数据库，NestJS 作为开发框架

在决定小程序创作语言的时候进行一些讨论，研究了写 H5 或者 React 框架转小程序的可行性，，使用基于 Vue3 语法的 Uniapp 框架

在决定了技术方案之后，进行了小组分工，由邓为先和董豪两位同学负责前端，其中邓为先主要负责网页端，董豪主要负责小程序端，后端由曾冠阳和刘靖潇同学负责



第四次会议

时间 2025.10.18 地点 C楼研讨间

填写产品规格文档和创作原型设计

完成小程序页面的设计讨论，确定了小程序主要分为五大功能模块，分别为主页、新闻、规划、AI和个人设置。在此基础上，在会议期间，进行了主页的原型页面设计。

同时在会议上讨论完成产品规格文档



第五次会议

时间 2025.10.27 地点 图书馆研讨间

主题：项目仓库初始化和框架初始化，技术方案进一步讨论和API接口制定

在 github 中进行了项目仓库的初始化，制定了 contributor.md 的开发规范和前后端的代码规范，同时创建了三个主要文件夹/backend，/frontend-miniapp，/frontend-web以便于三端分别开发。在src中创建了初始化的一些页面文件，pnpm 包管理、prettier 代码规范的初始化文件

进一步讨论了技术方案，并最终确定技术方案前端网页端使用 Vue3 + TypeScript，使用基于 Vue3 语法的 UniApp 框架和 TypeScript，使用微信开发者工具进行调试，前端使用 Tailwindcss 作为样式库；前后端接口制定使用Apifox；后端使用 TypeScript 语言，数据库使用 Prisma 和 PostgreSQL，容器化使用 Docker，缓存优化使用Redis，路由使用 Nginx

同时在APIFOX中建立项目，初步制定了项目小程序端和网页端的菜品和管理相关的接口，制定数据库的主要数据模型，包括 dish/user/admin/canteen 等

主题： API 接口最终完善和中期汇报准备

会议主要讨论和完善了项目绝大部分所需要的数据模型和 API 接口，涵盖了网页端菜品/审核/评论/权限/食堂/新闻的管理功能接口，小程序端涵盖认证/菜品/评价/食堂/评论/规划/AI推荐/新闻/用户中心，总计创建大约70个 API 接口，并且 API 路由和定义导入到实际的前后端框架中，以便统一的使用

主题：前后端框架搭建和方案讨论
