## 4. 主要观察
- 分支覆盖率显著低于语句/方法，缺口集中在异常兜底、弱网/中断、权限分支。
- API 包装层（src/api/modules/*）仍有未覆盖条件，建议补充错误码分支、取消/超时、重试与上传失败路径。
- AI 聊天、规划、筛选等复杂交互的组合式函数分支缺口明显，需用模拟请求/弱网场景覆盖 stop streaming、重入、筛选重置/输入校验等状态。

## 5. 改进建议
- 针对分支薄弱模块优先补测：网络异常、空数据、鉴权失效、弱网流式中断等场景。
- 为页面级组件增加快照与行为单测（交互事件 + DOM 断言），降低 UI 改动的破坏面。
- 将覆盖率阈值写入 Jest 配置（`coverageThreshold`），并在 CI 中开启 `pnpm test -- --coverage` 失败即阻断合并。
- 结合 E2E（Playwright/Uni Automator）回归脚本，对高风险业务（AI 聊天、规划、上传）做冒烟补充。
