3.  - # TasteInsight 网页管理端功能测试文档
    
    	本文档为 TasteInsight 网页管理端的功能测试用例集。覆盖了核心业务逻辑及异常处理。
    
    	---
    
    	## 1. 测试综述
    
    	### 1.1 测试环境
    
    	- **前端环境**: Chrome / Edge 最新版本
    	- **后端环境**: 正式服务器 API
    	- **测试账号**:
    	    - 超级管理员（拥有所有权限）
    	    - 普通管理员（受限权限，用于测试权限控制）
    	- **执行方式：**
    	    - 均为手动执行
    
    	### 1.2 模块概览
    
    	| 模块名称         | 对应页面/组件       | 关键功能点                             |
    	| :--------------- | :------------------ | :------------------------------------- |
    	| **认证授权**     | `Login.vue`         | 登录校验、权限跳转、忘记密码           |
    	| **食堂管理**     | `AddCanteen.vue`    | 楼层解析、营业时间、窗口管理、图片上传 |
    	| **菜品管理**     | `SingleAdd.vue`     | 级联选择、子项管理、口味指标、多图上传 |
    	| **批量导入**     | `BatchAdd.vue`      | Excel解析、错误处理                    |
    	| **人员管理**     | `UserManage.vue`    | 角色分配、权限依赖、密码强度、管理范围 |
    	| **评论评价审核** | `ReviewManage.vue`  | 待审核评价/评论处理、通过/拒绝流程     |
    	| **评论评价管理** | `CommentManage.vue` | 已发布内容检索、删除、图片预览         |
    	| **新闻公告**     | `NewsManage.vue`    | 富文本编辑、草稿/发布状态流转、预览    |
    	| **系统配置**     | `ConfigManage.vue`  | 全局/食堂配置区分、自动审核开关        |
    	| **举报处理**     | `ReportManage.vue`  | 举报详情、违规处理                     |
