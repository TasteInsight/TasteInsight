## 1. 系统登录

### 1.1 访问登录页面

打开浏览器，输入管理端网址进入登录页面。

> ![image-20260104220629766](../../../../AppData/Roaming/Typora/typora-user-images/image-20260104220629766.png)

### 1.2 登录步骤

1. **输入用户名**：在"用户名"输入框中填写您的管理员账号
2. **输入密码**：在"密码"输入框中填写您的登录密码
3. **记住我（可选）**：勾选"记住我"选项可在下次访问时自动填充用户名
4. **点击登录**：点击"登录"按钮进行身份验证

### 1.3 忘记密码

如果您忘记了登录密码，请点击"忘记密码？"链接，系统会弹出提示框告知您联系系统管理员进行密码重置。

> ![image-20260104220656332](../../../../AppData/Roaming/Typora/typora-user-images/image-20260104220656332.png)

### 1.4 登录失败处理

- **用户名或密码错误**：请检查输入是否正确，注意大小写
- **账号被禁用**：请联系超级管理员恢复账号
- **网络错误**：请检查网络连接后重试

## 3. 菜品管理

### 3.1 单个菜品上传

#### 3.1.1 进入上传页面

点击左侧菜单"菜品上传"→"单个上传"进入单个菜品上传页面。

> ![image-20260104221341078](../../../../AppData/Roaming/Typora/typora-user-images/image-20260104221341078.png)

#### 3.1.2 基本信息填写

**必填信息：**

1. **选择食堂**：从下拉菜单中选择菜品所属的食堂

2. **选择窗口**：选择食堂后，从下拉菜单中选择具体的售卖窗口

3. **菜品名称**：输入菜品的名称（必填）

4. **菜品价格**：如果菜品只有一个规格，直接输入价格；如果有多个规格，则通过"子项"方式添加

**选填信息：**

5. **菜品描述**：详细描述菜品的特点、口味等信息

6. **菜品图片上传**：
   - 点击"添加图片"按钮或拖拽图片到上传区域
   - 支持批量上传多张图片
   - 第一张图片默认为封面图
   - 可以通过点击图片上的"设为封面"按钮更换封面
   - 支持删除已上传的图片

   > ![image-20260104221607796](../../../../AppData/Roaming/Typora/typora-user-images/image-20260104221607796.png)

#### 3.1.3 菜品子项（多规格）

如果菜品有多种规格（如大份/小份、不同配料等），可以添加子项：

1. 点击"添加子项"按钮
2. 输入子项名称（如"大份"、"小份"）
3. 输入子项价格
4. 可以添加多个子项
5. 点击子项旁的删除按钮可移除

> 📷 **【配图位置】**：子项添加区域截图，展示多个子项

**注意**：添加子项后，菜品的价格将由子项决定，主价格输入框将被禁用。

#### 3.1.4 菜系标签（TAG）

为菜品添加分类标签，便于用户搜索和筛选：

1. 在"菜系TAG"区域，点击已有标签可直接添加
2. 也可以在输入框中输入自定义标签后按回车添加
3. 点击已添加标签的"×"可移除

常用标签示例：川菜、粤菜、清真、素食、米饭、面食等

#### 3.1.5 口味指标设置

设置菜品的口味特征，帮助用户了解菜品口味：

| 指标 | 说明 | 范围 |
|------|------|------|
| 辣度 | 菜品的辛辣程度 | 0-5（0=不辣，5=特辣） |
| 咸度 | 菜品的咸淡程度 | 0-5 |
| 甜度 | 菜品的甜味程度 | 0-5 |
| 油度 | 菜品的油腻程度 | 0-5 |

> 📷 **【配图位置】**：口味指标滑块设置截图

#### 3.1.6 供应时间设置

设置菜品的供应时段：

- ☑️ 早餐
- ☑️ 午餐
- ☑️ 晚餐
- ☑️ 夜宵

勾选相应的时段表示该菜品在该时段供应。

#### 3.1.7 供应日期段设置

如果菜品只在特定日期范围内供应（如限时特惠、季节性菜品）：

1. 点击"添加日期段"按钮
2. 选择开始日期和结束日期
3. 可以添加多个日期段
4. 留空表示长期供应

#### 3.1.8 其他信息

**过敏原信息**：填写菜品中可能引起过敏的成分，如"含花生、蛋类"

**原辅料信息**：填写菜品的主要原料和辅料

#### 3.1.9 保存提交

填写完成后，点击页面底部的"上传菜品"按钮提交。

- 提交成功后系统会显示成功提示
- 菜品将进入待审核状态（如果开启了审核功能）
- 您可以选择继续添加新菜品或返回修改

---

### 3.2 批量菜品上传

#### 3.2.1 进入批量上传页面

点击左侧菜单"菜品上传"→"批量上传"进入批量上传页面。

> ![image-20260104233944107](../../../../AppData/Roaming/Typora/typora-user-images/image-20260104233944107.png)

#### 3.2.2 下载模板

1. 点击"下载模板"按钮下载 Excel 模板文件
2. 模板中包含了所有需要填写的字段及说明

#### 3.2.3 填写Excel模板

模板字段说明：

| 字段名 | 是否必填 | 说明 |
|--------|----------|------|
| 食堂名称 | ✓ | 必须与系统中已有食堂名称完全一致 |
| 窗口名称 | ✓ | 必须与系统中已有窗口名称完全一致 |
| 菜品名称 | ✓ | 菜品的名称 |
| 菜品价格 | ✓ | 数字格式，如 15 或 15.5 |
| 菜品描述 | | 菜品的详细描述 |
| 菜系TAG | | 多个标签用逗号分隔 |
| 辣度 | | 0-5的整数 |
| 咸度 | | 0-5的整数 |
| 甜度 | | 0-5的整数 |
| 油度 | | 0-5的整数 |
| 供应时间 | | breakfast,lunch,dinner,nightsnack |
| 过敏原 | | 过敏原信息 |
| 原辅料 | | 主要原料信息 |

#### 3.2.4 上传Excel文件

1. 点击上传区域或将文件拖拽到上传区域
2. 支持 .xlsx 和 .xls 格式
3. 系统会自动解析文件内容

#### 3.2.5 数据预览与验证

上传后，系统会显示数据预览表格：

- **绿色行**：数据验证通过，可以提交
- **黄色行**：数据有警告，建议检查但可提交
- **红色行**：数据有错误，必须修正后才能提交

> ![image-20260104234007439](../../../../AppData/Roaming/Typora/typora-user-images/image-20260104234007439.png)

#### 3.2.6 错误处理

如果有错误数据：

1. 查看错误行的具体错误提示
2. 点击"导出错误列表"按钮下载错误详情
3. 在 Excel 中修正错误
4. 重新上传修正后的文件

#### 3.2.7 提交数据

确认数据无误后：

1. 点击"提交有效数据"按钮
2. 系统会批量创建所有验证通过的菜品
3. 提交完成后显示成功/失败的数量统计

### 3.3 菜品浏览与修改

#### 3.3.1 进入菜品修改页面

点击左侧菜单"菜品修改"进入菜品管理页面。

> ![image-20260104234223258](../../../../AppData/Roaming/Typora/typora-user-images/image-20260104234223258.png)

#### 3.3.2 搜索与筛选

**搜索功能**：
- 在搜索框中输入菜品名称关键词
- 按回车或点击搜索按钮进行搜索

**筛选功能**：
- **食堂筛选**：选择特定食堂查看该食堂的菜品
- **窗口筛选**：选择特定窗口查看该窗口的菜品

#### 3.3.3 菜品列表

列表显示以下信息：

| 列名 | 说明 |
|------|------|
| 菜品名称 | 菜品名称和缩略图 |
| 所属位置 | 食堂-窗口 |
| 标签 | 菜品的菜系TAG |
| 价格 | 菜品价格或价格范围 |
| 评分 | 用户平均评分 |
| 操作 | 查看/编辑按钮 |

#### 3.3.4 查看菜品详情

点击列表中的"查看"按钮，可以在弹窗中查看菜品的完整信息。

#### 3.3.5 编辑菜品

1. 点击列表中的"编辑"按钮
2. 进入编辑页面，显示菜品当前的所有信息
3. 修改需要更新的字段
4. 点击"保存修改"按钮提交更改

编辑页面的字段与新建菜品页面相同，请参考 [3.1 单个菜品上传](#31-单个菜品上传)。

### 3.4 菜品审核

#### 3.4.1 进入审核页面

点击左侧菜单"菜品审核"进入待审核菜品列表页面。

> ![image-20260104221902532](../../../../AppData/Roaming/Typora/typora-user-images/image-20260104221902532.png)

#### 3.4.2 审核列表

列表显示待审核的菜品信息：

| 列名 | 说明 |
|------|------|
| 菜品名称 | 菜品名称和缩略图 |
| 所属位置 | 食堂-窗口 |
| 提交日期 | 菜品上传的日期 |
| 提交时间 | 菜品上传的时间 |
| 提交人 | 上传该菜品的管理员 |
| 状态 | pending/approved/rejected |
| 操作 | 审核按钮 |

#### 3.4.4 审核详情

点击"审核"按钮进入审核详情页面，查看菜品的完整信息：

- 左侧：食堂窗口信息、菜品名称、描述、图片
- 右侧：子项、供应信息、供应时间、日期段、过敏原、原辅料、提交信息

> ![image-20260104222442819](../../../../AppData/Roaming/Typora/typora-user-images/image-20260104222442819.png)

#### 3.4.5 审核操作

在审核详情页面底部有三个操作按钮：

1. **批准通过**：
   - 点击"批准通过"按钮
   - 确认后菜品状态变为"已通过"
   - 菜品将在小程序端展示

2. **拒绝审核**：
   - 点击"拒绝审核"按钮
   - 弹出拒绝原因输入框
   - 填写拒绝原因（建议填写以便提交者修改）
   - 点击"确认拒绝"完成操作

   > ![image-20260104222555171](../../../../AppData/Roaming/Typora/typora-user-images/image-20260104222555171.png)

3. **撤销审核结果**：
   - 适用于已通过或已拒绝的菜品
   - 点击后菜品状态恢复为"待审核"
   - 已上架的菜品将被下架

## 4. 食堂信息管理

### 4.1 食堂信息浏览

#### 4.1.1 进入食堂管理页面

点击左侧菜单"食堂信息管理"进入食堂列表页面。

> ![image-20260104222816536](../../../../AppData/Roaming/Typora/typora-user-images/image-20260104222816536.png)

#### 4.1.2 食堂列表

列表显示以下信息：

| 列名 | 说明 |
|------|------|
| 食堂信息 | 食堂图片、名称和描述 |
| 位置 | 食堂的地理位置 |
| 窗口数量 | 该食堂下的窗口数量 |
| 评分 | 食堂的平均评分 |
| 操作 | 编辑/删除按钮 |

#### 4.1.3 搜索食堂

在搜索框中输入食堂名称或位置关键词进行搜索。

---

### 4.2 新建食堂

#### 4.2.1 点击新建按钮

在食堂列表页面，点击右上角"新建食堂"按钮。

#### 4.2.2 填写基本信息

1. **食堂名称**（必填）：输入食堂的名称，如"紫荆园"

2. **食堂位置**（选填）：输入食堂的地理位置，如"清华大学紫荆公寓区"

3. **楼层信息**（必填）：
   - 输入食堂的楼层信息
   - 支持格式：一层、1F、B1、地下二层等
   - 多个楼层用"/"分隔，如"一层/二层/B1"
   - 楼层范围：地下2层到地上5层

   > ![image-20260104223127096](../../../../AppData/Roaming/Typora/typora-user-images/image-20260104223127096.png)

4. **食堂描述**（选填）：详细描述食堂的特点

#### 4.2.3 上传食堂图片

1. 点击"添加图片"按钮或拖拽图片到上传区域
2. 第一张图片自动设为封面图
3. 封面图会进行正方形裁剪显示
4. 其他图片保持原比例显示
5. 支持批量上传

#### 4.2.4 保存食堂

点击"保存食堂信息"按钮提交。保存成功后，系统会提示您可以继续添加窗口信息。

**重要提示**：必须先保存食堂基本信息（包含楼层信息）后，才能添加营业时间和窗口。

---

### 4.3 编辑食堂信息

#### 4.3.1 进入编辑页面

在食堂列表中，点击要编辑的食堂行，或点击"编辑"按钮。

#### 4.3.2 修改信息

编辑页面与新建页面相同，可以修改：
- 食堂名称、位置、描述
- 楼层信息
- 食堂图片

#### 4.3.3 保存修改

修改完成后点击"保存修改"按钮提交更改。

---

### 4.4 窗口管理

#### 4.4.1 添加窗口

在食堂编辑页面的"窗口管理"区域：

1. 点击"添加窗口"按钮
2. 填写窗口信息：
   - **窗口名称**（必填）：如"川湘风味"
   - **窗口所在楼层**（必填）：从下拉菜单选择
   - **窗口编号**（选填）：如"01"、"A01"

   > ![image-20260104223314730](../../../../AppData/Roaming/Typora/typora-user-images/image-20260104223314730.png)

3. 可以添加多个窗口
4. 保存食堂时会一并保存窗口信息

#### 4.4.2 编辑窗口

直接在窗口列表中修改窗口的名称、楼层或编号。

#### 4.4.3 删除窗口

点击窗口行右侧的删除按钮，确认后删除该窗口。

5. **生效结束时间**（选填）：
   - 选择实验结束的时间
   - 留空表示永久有效，直到手动完成实验

---

### 10.3 实验分组配置

#### 10.3.1 添加分组

1. 点击"添加分组"按钮
2. 设置分组信息：
   - **分组名称**：如"对照组"、"实验组A"
   - **组内占比**：该组在实验中的用户比例（0-1之间）

> ![image-20260104233323489](../../../../AppData/Roaming/Typora/typora-user-images/image-20260104233323489.png)

**注意**：所有分组的占比总和必须等于1（100%）

#### 10.3.2 均分占比

如果有多个分组，可以点击"均分占比"按钮自动平均分配各组比例。

#### 10.3.3 配置权重和召回配额

点击分组的"配置权重和召回配额"链接，弹出配置弹窗：

**权重配置（Weights）**：

| 参数 | 说明 |
|------|------|
| 偏好匹配 | 用户偏好与菜品的匹配度权重 |
| 收藏相似度 | 与用户收藏菜品的相似度权重 |
| 浏览相关性 | 与用户浏览历史的相关性权重 |
| 菜品质量 | 菜品评分和质量指标权重 |
| 多样性 | 推荐结果多样性权重 |
| 搜索相关性 | 搜索词相关性权重 |

**召回配额配置（Recall Quota）**：

| 参数 | 说明 |
|------|------|
| 向量召回配额 | 向量相似度召回的比例 |
| 规则召回配额 | 规则匹配召回的比例 |
| 协同过滤召回配额 | 协同过滤召回的比例 |

**注意**：召回配额的总和应为1（100%）

#### 10.3.4 保存实验

配置完成后，点击"创建实验"按钮保存。新创建的实验默认为草稿状态。

### 10.4 实验状态管理

#### 10.4.1 查看实验详情

在实验列表中点击"查看"按钮，进入实验详情页面。

详情页显示：
- 基本信息：名称、状态、创建时间、生效时间、流量占比
- 实验分组列表：每个分组的名称和占比

#### 10.4.2 启动实验

对于草稿状态的实验，点击"启动实验"按钮：
- 实验状态变为"运行中"
- 实验将在生效时间范围内对用户生效

#### 10.4.3 暂停实验

对于运行中的实验，点击"暂停实验"按钮：
- 实验状态变为"已暂停"
- 实验暂时不再对用户生效

#### 10.4.4 恢复实验

对于已暂停的实验，点击"恢复实验"按钮：
- 实验状态恢复为"运行中"
- 实验重新对用户生效

#### 10.4.5 完成实验

对于运行中或已暂停的实验，点击"完成实验"按钮：
- 实验状态变为"已完成"
- 实验永久停止，无法恢复

#### 10.4.6 实验生效状态

当实验状态为"运行中"时，系统还会显示实际生效状态：
- **实验生效中**（绿色）：当前时间在生效时间范围内
- **未在生效时间内**（灰色）：当前时间不在生效时间范围内

#### 10.4.7 编辑实验

点击"编辑实验"按钮可以修改实验的配置信息。

#### 10.4.8 删除实验

1. 点击"删除"按钮
2. 确认删除操作
3. 实验将被永久删除

**警告**：删除操作不可恢复。

## 12. 常见问题

### Q1: 登录后显示"无权限访问"怎么办？

**A**: 这表示您的账号没有访问该功能的权限。请联系超级管理员为您分配相应权限。

### Q2: 上传图片失败怎么办？

**A**: 请检查：
1. 图片大小是否超过10MB
2. 图片格式是否为JPG、PNG、GIF等常见格式
3. 网络连接是否正常

### Q3: 批量上传Excel解析失败？

**A**: 请确保：

1. 食堂名称和窗口名称与系统完全一致
2. 必填字段都已填写
3. 数值字段填写的是数字格式

### Q4: 修改密码后无法登录？

**A**: 请确认：
1. 新密码输入是否正确（注意大小写）
2. 清除浏览器缓存后重试
3. 如仍无法登录，请联系管理员重置密码

### Q5: 审核通过的菜品在小程序看不到？

**A**: 可能的原因：
1. 菜品的供应时间未包含当前时段
2. 菜品的供应日期段不在当前日期
3. 缓存未刷新，请稍后再试

### Q6: 如何批量删除数据？

**A**: 目前系统不支持批量删除操作，需要逐条删除。如需批量操作，请联系技术人员协助。
