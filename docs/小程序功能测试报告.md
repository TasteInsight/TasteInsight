  - # TasteInsight 小程序用户前端功能测试文档

	本文档为 TasteInsight 小程序端（UniApp / 微信小程序）功能测试用例集。覆盖核心业务流程、关键交互、异常处理及与 AI 模块相关的特殊测试前置条件。

	---

	## 1. 测试综述

	### 1.1 测试环境

	- **运行环境**:
	    - 微信开发者工具（稳定版）
	    - 真机：Android / iOS（建议至少各 1 台）
	- **后端环境**: 服务器 API（按项目当前配置，建议固定一套“测试环境”以便复现）
	- **小程序发布/测试限制（重要）**:
	    - 由于小程序包含 AI 模块，**无法以个人主体上线**。
	    - 测试需使用 **体验版/测试版**，并由小程序管理员在微信公众平台为测试人员开通 **体验权限**。
	    - **体验权限申请流程（建议执行顺序）**:
	        1. 测试人员准备自己的微信号（WeChat ID）/手机号等可用于后台添加的身份信息。
	        2. 向小程序管理员提交申请（建议备注“体验权限-功能测试”）。
	        3. 管理员在公众平台添加“体验成员/测试成员”。
	        4. 测试人员使用微信扫码体验二维码或通过开发者工具预览进入。
	        5. 若出现“无权限访问/不在体验成员列表”等提示，优先核对是否已被添加到体验成员。
	- **测试账号**:
	    - 普通用户（微信授权登录）
	- **网络（建议）**:
	    - 网络：在校园网环境下测试
	- **执行方式：**
	    - 均为手动执行

	### 1.2 模块概览

	| 模块名称 | 对应页面/组件 | 关键功能点 |
	| :-- | :-- | :-- |
	| **认证登录** | `/pages/login/index` | 授权登录、登录态保持、未登录拦截 |
	| **首页** | `/pages/index/index` | 下拉刷新、推荐/入口跳转、列表展示 |
	| **搜索** | `/pages/search/index` | 关键词搜索、结果列表、跳转菜品/窗口 |
	| **食堂** | `/pages/canteen/index` | 食堂列表、下拉刷新、进入窗口 |
	| **窗口** | `/pages/window/index` | 窗口信息、菜品列表、跳转菜品 |
	| **菜品详情** | `/pages/dish/index` | 详情展示、评价/评论、收藏、下拉刷新 |
	| **新闻公告** | `/pages/news/index` + `/pages/news/components/detail` | 列表/详情、下拉刷新、内容展示 |
	| **菜单规划** | `/pages/planning/index` | 当前/历史 Tab、弹窗详情/新建/编辑、删除、执行、下拉刷新 |
	| **AI 聊天** | `/pages/ai-chat/index` | 对话列表、建议词、流式回复、停止生成、历史会话、规划卡片应用 |
	| **我的** | `/pages/profile/index` + `/pages/profile/my-favorites/index` + `/pages/profile/my-reviews/index` + `/pages/profile/history/index` | 用户信息、入口聚合、收藏列表、我的评价、历史浏览、下拉刷新 |
	| **设置** | `/pages/settings/index` + 子页（`/pages/settings/components/*` + `/pages/settings/privacy` + `/pages/settings/about`） | 个人信息（昵称/头像裁剪上传）、偏好/过敏原、显示/通知设置、隐私与关于 |
	| **添加菜品（用户上传）** | `/pages/add-dish/index` | 必填校验、选择食堂/窗口、上传图片（最多9张）、标签/过敏原、提交后等待审核 |
	| **彩蛋** | `/pages/easter-egg/index` | 关于页隐藏入口、彩蛋页基础交互 |
