# 可选环境变量参考

后端的开发与部署模板只列出常用配置。启用某项能力时，将对应变量加入正在使用的私有 env 文件；其他配置继续使用应用默认值。环境变量优先于文件，生产容器按角色选取字段。

## 身份、存储、嵌入、通知与 AI

以下注释值用于查阅；按需取消注释并填写实际值。开发与生产使用独立凭据，`VITE_*` 仅承载可公开的前端构建参数。

## 容器与外部连接

```dotenv
# Bundled services are the default. Override addresses when connecting external services.
# POSTGRES_HOST=db
# POSTGRES_PORT=5432
# POSTGRES_SSLMODE=require
# Optional complete connection override; otherwise POSTGRES_* generates the URL.
# DATABASE_URL=postgresql://app:encoded-password@database.example.invalid:5432/tasteinsight?schema=public
# REDIS_HOST=redis
# REDIS_PORT=6379
# External embedding endpoint; the application switch and container selection are independent.
# EXTERNAL_EMBEDDING_SERVICE_ENABLED=true
# EXTERNAL_EMBEDDING_SERVICE_URL=https://embedding.example.invalid
# Start the bundled Python service when needed.
# COMPOSE_PROFILES=embedding
# IMAGE_REGISTRY=ghcr.io/tasteinsight
# TAG=latest
# GATEWAY_BIND_HOST=0.0.0.0
# TLS_CERT_FILE=fullchain.pem
# TLS_KEY_FILE=private.key
# NGINX_IMAGE=nginx:1.28-alpine
# WORKER_STOP_GRACE_PERIOD=90s
```

PostgreSQL 的 `POSTGRES_SSLMODE` 可按服务端要求选择 `disable`、`prefer`、`require`，对应当前 [Prisma PostgreSQL 连接器](https://docs.prisma.io/docs/orm/v6/overview/databases/postgresql) 支持的选项。需要客户端证书等额外连接参数时，应按连接器配置并单独验收。Redis 连接沿用当前 TCP 地址、端口和口令配置；需要 TLS 或集群协议的托管产品，应另行核对客户端支持。

Python 独立运行和训练参数见 [嵌入服务配置](../backend/python-embedding-service/env.example)。运维参数见 [ops](../ops/README.md)，压测参数见 [perf](../perf/README.md)。
